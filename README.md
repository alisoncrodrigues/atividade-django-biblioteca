
# Projeto Django - Biblioteca

## Sobre o projeto

Projeto desenvolvido como atividade prática de programação utilizando o framework Django.

A aplicação apresenta uma interface de login e uma página de cadastro de usuários, permitindo a navegação entre diferentes páginas HTML.

## Funcionalidades

- Página inicial de Login.
- Página de Cadastro de Usuário.
- Navegação entre as páginas.
- Formulários HTML.
- Estilização utilizando CSS.

## Tecnologias utilizadas

- Python
- Django
- HTML5
- CSS3

## Como executar o projeto

### 1. Clonar o repositório

git clone URL_DO_REPOSITORIO

### 2. Entrar na pasta

cd atividade-django-biblioteca

### 3. Criar o ambiente virtual

python -m venv venv

### 4. Ativar o ambiente virtual (Windows)

.\venv\Scripts\Activate.ps1

### 5. Instalar as dependências

python -m pip install -r requirements.txt

### 6. Executar as migrations

python manage.py migrate

### 7. Iniciar o servidor

python manage.py runserver

Acesse pelo navegador:

http://127.0.0.1:8000/
